# Security Policy

## Supported versions

Only the latest release published on [WordPress.org](https://wordpress.org/plugins/wp-mail-validator/) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue.

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/kimpenhaus/mail-validator/security/advisories/new).
You will get a response as soon as possible; once a fix is released, the advisory will be published and you will be credited unless you prefer otherwise.
